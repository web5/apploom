# AI 研发平台原型设计方案

> 日期: 2026-08-10
> 状态: 已确认

## 一、产品定位

**一句话描述**：面向产品经理和创业者，输入一句话或文档，AI 自动完成需求拆解、技术方案、代码生成到发布上线的全流程平台。

**目标用户**：产品经理 / 创业者（非技术背景，有想法但不会写代码）

**核心价值**：把"想法→上线产品"的周期从数周缩短到数分钟

## 二、整体架构

采用 **AI Pipeline 编排引擎驱动** 的架构，四层分层设计：

### 2.1 前端应用层
- **对话工作台**：用户与 AI 的主要交互入口
- **项目看板**：项目列表、进度管理、活动动态
- **管理后台 / 模板市场**：用户管理、计费、模板浏览

### 2.2 API 网关层
- 认证 / 路由 / 限流

### 2.3 AI Pipeline 编排引擎（核心）
四个 Agent 串联协作：

| Agent | 职责 | 输入 | 产出 |
|-------|------|------|------|
| 需求分析 Agent | 解析需求，生成结构化 PRD | 一句话/文档 | 产品概述、功能列表(P0-P2)、用户故事、数据实体 |
| 架构设计 Agent | 基于PRD设计技术方案 | 确认后的PRD | 技术选型、页面结构树、数据模型(ER)、API列表、原型图 |
| 代码生成 Agent | 根据方案生成多端代码 | 确认后的方案 | Web(React/Next.js)、小程序(Taro)、App(RN/Flutter)代码 |
| 部署发布 Agent | 构建打包并发布 | 确认后的代码 | 内置云托管URL / 代码导出到Git仓库 |

### 2.4 基础服务层
- 用户服务、项目服务、模板服务、计费服务、部署服务
- 数据存储: PostgreSQL · Redis · 对象存储 · 代码仓库

## 三、核心交互模式

**混合模式**——用户可灵活配置每个环节的参与度：

- **全自动模式**：输入需求后，AI 全自动完成拆解→设计→编码→发布，用户只需最终确认上线
- **逐步确认模式**：每个环节完成后暂停，用户查看产出物并确认后才继续下一环节

可在项目设置中全局配置，也可在单个节点临时切换。

## 四、前端页面结构

### 4.1 页面地图

```
AI 研发平台
├── 首页 / 落地页（未登录）
├── 工作台（登录后首页）
│   ├── 项目列表（卡片/列表切换）
│   │   ├── 进行中项目
│   │   ├── 已完成项目
│   │   └── 草稿箱
│   ├── 快速创建入口（输入一句话 / 上传文档）
│   └── 最近活动动态
├── 项目工作区（核心页面）
│   ├── 对话面板（左侧）
│   ├── 流水线看板（中间）
│   └── 产出预览（右侧）
├── 模板市场
├── 发布管理
└── 设置中心
```

### 4.2 项目工作区（三栏布局）

核心页面，采用三栏布局：

- **左栏 - 对话面板**（280px）：用户与 AI 的主要交互入口。输入需求修改、提问、指令操作
- **中栏 - 流水线看板**（弹性宽度）：可视化展示当前项目进度。四个主节点（需求→方案→代码→发布），每个节点可点击展开查看产出物
- **右栏 - 产出预览**（300px）：根据选中的节点展示对应产出物预览（PRD / 原型图 / 代码 / 运行预览）

三栏宽度可拖拽调整，左右栏可折叠收起。

## 五、AI Pipeline 各环节详细设计

### 5.1 环节 1：需求拆解（需求分析 Agent）

**输入**：一句话描述 / 文档上传（PDF、Word、Markdown、图片）

**AI 处理**：
- 解析输入内容，提取核心需求
- 补充合理的产品功能假设
- 生成结构化 PRD

**产出**：
- 产品概述（定位、目标用户、核心价值）
- 功能列表（分优先级 P0/P1/P2）
- 用户故事（As a... I want to... so that...）
- 页面清单
- 数据实体（核心业务对象）

**用户交互**：查看 PRD，通过对话修改需求，AI 实时更新

### 5.2 环节 2：方案设计（架构设计 Agent）

**输入**：确认后的 PRD

**AI 处理**：技术选型、页面结构设计、数据模型设计、API 设计、原型图生成

**产出**：
- 技术方案文档（选型、页面结构树、路由、ER图、API列表）
- 低保真原型图（每页面的线框图）

**用户交互**：预览原型图，通过对话调整

### 5.3 环节 3：代码生成（代码生成 Agent）

**输入**：确认后的技术方案 + 原型图

**AI 处理**：生成前端代码、后端代码、配置文件

**产出**：
- 完整可运行的项目代码
- 代码结构树
- 实时预览（Web 端可直接在平台内预览）

**用户交互**：在线预览、对话修改、查看和编辑代码

### 5.4 环节 4：发布上线（部署发布 Agent）

**输入**：确认后的代码

**AI 处理**：构建打包、部署到内置云环境或导出到 Git 仓库

**产出**：
- 内置云托管：可访问的线上 URL
- 代码导出：Git 仓库链接
- 部署日志和状态

**用户交互**：选择发布方式、配置自定义域名、查看发布历史和回滚

## 六、用户管理与商业化

### 6.1 用户体系

**注册登录**：手机号+验证码 / 微信扫码 / 邮箱注册

**用户角色**：
- 个人用户：独立使用，个人项目空间
- 团队用户：创建团队，成员协作，共享项目

**团队权限**：管理员 / 编辑者 / 查看者

### 6.2 项目管理

**生命周期**：草稿 → 进行中 → 待发布 → 已发布 → 已归档

**项目设置**：名称/描述/图标、目标平台选择、流水线模式配置、协作成员管理、版本历史

### 6.3 模板市场

**分类**：按行业（电商/教育/餐饮/医疗/企业服务）、按功能（落地页/管理后台/表单/社区）、按平台

**模板内容**：预置 PRD、技术方案、原型图、预览效果、使用次数和评分

### 6.4 计费体系

| 版本 | 价格 | 项目数 | AI算力 | 云托管 | 代码导出 | 团队 |
|------|------|--------|--------|--------|----------|------|
| 免费版 | 0 | 3个/月 | 基础 | 子域名 | - | - |
| 专业版 | 月付/年付 | 无限 | 高级 | 自定义域名 | 支持 | - |
| 团队版 | 月付/年付 | 无限 | 高级 | 自定义域名 | 支持 | 最多N人 |
| 企业版 | 定制 | 无限 | 定制 | 私有化 | 支持 | 不限 |

**算力点数**：所有版本消耗 AI 算力点数，不同操作消耗不同点数。免费版每月赠送，付费版可购买额外点数。

## 七、技术选型参考

| 层级 | 技术选型 |
|------|---------|
| 前端 | React + Next.js + TypeScript |
| 后端 | Node.js (Nest.js) / Python (FastAPI) |
| 数据库 | PostgreSQL + Redis |
| AI 模型 | GPT-4 / Claude / 本地模型（按场景选择） |
| 代码生成 | 多模型协作，CodeLlama / DeepSeek-Coder |
| 部署 | Docker + Kubernetes / Serverless |
| 对象存储 | S3 兼容存储 |
| 代码仓库 | 内置 Git 服务 + 对接 GitHub/GitLab |

## 八、多端代码生成策略

| 目标平台 | 技术栈 | 说明 |
|---------|--------|------|
| Web | React + Next.js + Tailwind CSS | SSR/SSG，响应式设计 |
| 小程序 | Taro 3 (React 语法) | 一套代码编译多端小程序 |
| App | React Native / Expo | 跨平台，共享业务逻辑 |

统一使用 TypeScript，共享数据模型定义和 API 客户端代码。
